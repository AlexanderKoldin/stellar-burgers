# Stellar Burgers

SPA космической бургерной: пользователь собирает бургер из ингредиентов, оформляет заказ и видит его в ленте заказов и в личном кабинете.

**Стек:** React 18 · TypeScript · Redux Toolkit · React Router v6 · Webpack · Storybook · Jest · Playwright · GitHub Actions

## Что умеет приложение

- **Конструктор бургера.** Выбор булки и начинок, удаление и перестановка ингредиентов, счётчики на карточках, итоговая цена.
- **Оформление заказа** с номером заказа в модальном окне.
- **Лента заказов и история заказов** пользователя со статусами.
- **Модальные окна со своим URL.** Детали ингредиента и заказа открываются поверх страницы через `location.state.background`, а по прямой ссылке — отдельной страницей.
- **Авторизация:** регистрация, вход, восстановление и сброс пароля, редактирование профиля, выход.
- **Защищённые маршруты.** Компонент `ProtectedRoute` закрывает профиль от гостей и страницы входа от авторизованных, после входа возвращает на исходную страницу.
- **Обновление токена.** Access-токен хранится в cookie, refresh-токен — в localStorage; при истёкшем токене запрос повторяется после обновления.

## Как устроено состояние

Redux Toolkit, отдельный слайс на каждую область данных: `ingredients`, `constructor`, `order`, `feeds`, `user`. Запросы к API — через `createAsyncThunk`, селекторы вынесены в отдельный модуль, чтобы компоненты не перерисовывались лишний раз. Состояние создания заказа и просмотра заказа разделено.

## Тесты и CI

- **Unit (Jest):** редьюсеры и асинхронные экшены всех слайсов.
- **E2E (Playwright):** сборка бургера, оформление заказа, открытие и закрытие модальных окон. Ответы API записаны в HAR-файлы, поэтому тесты не зависят от сервера.
- **GitHub Actions** запускает E2E-тесты на каждый пуш и пул-реквест.

## Запуск

```bash
npm install
cp .env.example .env   # адрес API в BURGER_API_URL
npm start              # dev-сервер
npm test               # unit-тесты
npm run test:e2e       # e2e-тесты
npm run storybook      # каталог UI-компонентов
```
